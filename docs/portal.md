# Infinite Dimensions AI research portal

The public GitHub Pages site at https://infinite-dimensions-ai.github.io/research-telecom-big-data-analytics/ hosts documentation and an interactive Three.js demo. The React/Vite application is packaged at `/demo/` under the same GitHub Pages site.

For an **authenticated private research portal**, deploy a separate portal application behind authentication and import/link to these research applications. **GitHub Pages is public even when associated repositories are private in plans that permit private repository Pages.** Never put credentials, unpublished research secrets, confidential data, or unpublished commercial intellectual property into public Pages artifacts.

The visual reference is rich explorable three-dimensional interaction (for example Bruno Simon's work), not a copy of another creator's assets or code. Add authored assets and progressively richer interactive experiments later.
