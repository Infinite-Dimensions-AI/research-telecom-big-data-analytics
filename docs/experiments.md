# Experiments

## Question

How do operational and social relationships improve prediction and intervention decisions in historical telecom data?

## Historical baseline / comparator

Logistic regression, random forests, survival modelling, centrality metrics, association rules, Hadoop, MapReduce and early Spark.

## Modern follow-up

Temporal graph neural networks, transformers, causal uplift analysis and accountable decision policies.

## Demonstration

The current web application visualises a simulated graph and evaluates one **synthetic baseline**, entirely separate from measured research. Expand into domain-specific controlled experiments, visualisations, and hardware-calibrated evaluations.
